// COMENTÁRIOS E ETIQUETAS
// Linhas começando com // são comentários, exceto comandos reconhecidos.
// // no meio de uma linha remove o restante na projeção (evite URLs na letra).
// #* seguido de qualquer nome identifica a estrofe e não é projetado.
// Exemplos de etiquetas: #*verso 1, #*refrão, #*ponte, #*final.
// Não há comando de repetição automática: copie a estrofe para repeti-la.
#*refrão
**Destaque/negrito** e ==destaque==
*Itálico* __sublinhado__ ~~riscado~~
// Os marcadores ** e == ativam o mesmo destaque visual do tema.
// Não combine marcadores Markdown aninhados: não é Markdown completo.
[fonte: Arial]Fonte do trecho[/fonte]
[cor: #FFD700]Cor do trecho[/cor]
[tamanho: 56]Tamanho do trecho[/tamanho]
[sombra: #000000]Sombra/fundo do trecho[/sombra]
// Tags podem ser aninhadas; feche-as antes do final da linha.
// Tags e nomes de comandos aceitam maiúsculas/minúsculas.
// Cores: #RGB, #RRGGBB ou #RRGGBBAA. Tamanhos > 0; decimais com ponto.

// TODOS OS NOMES ALTERNATIVOS DE COMANDOS DE SLIDE
// Nomes para fonte: fonte, font, f. Exemplo: //f: Arial
// Nomes para cor: cor, color, c. Exemplo: //c: #FFF
// Nomes para tamanho: tamanho, size, t, s. Exemplo: //t: 44
// Sombra/fundo: sombra, shadow, fundo, box, b. Exemplo: //b: #000
// Alinhamento: alinhar, align, a. Exemplo: //a: centro
// Valores horizontais: centro/center/c; esquerda/left/l/e;
// direita/right/r/d; justificado/justify/j (conforme suporte do renderizador).
// Espaçamento entre linhas: linha, line, l. Exemplo: //l: 1.4
// Espaçamento entre letras: letra, letter, ls. Exemplo: //ls: 1.5
// Vertical: valign, valinhar, va. Exemplo: //va: centro
// Valores verticais: topo/top/t/cima; centro/center/c/meio;
// inferior/bottom/b/baixo/terço inferior/terco inferior.
// Prefira sempre os dois-pontos. Para linha/line/l, eles são obrigatórios.
// Para os demais, também se aceita espaço: //f Arial ou // a centro.
// TAGS DE TRECHO (sempre com dois-pontos no início e / no fechamento):
// fonte/font/f; cor/color/c; tamanho/size/t/s; sombra/shadow/fundo/box/b.
// Exemplos: [f: Arial]texto[/f], [c: #FFF]texto[/c],
// [t: 50]texto[/t], [b: #000]texto[/b]. Alinhamento não é tag de trecho.
#*ponte

//c: #FFFFFF
//t: 44
//b: #000000
//a: center
//va: center
//l: 1.4
//ls: 1.5

// QUEBRAS CONDICIONAIS (não criam outro slide)
// | ou [br]: quebra em telas 4:3; nos demais formatos vira espaço.
// [4:3], [4x3], |4:3|, |4x3|, [quebra: 4:3], [quebra: 4x3].
// [16:9], [16x9], |16:9|, |16x9|, [quebra: 16:9], [quebra: 16x9].
// [9:16], [9x16], |9:16|, |9x16|, [quebra: 9:16], [quebra: 9x16].
// [21:9], [21x9], |21:9|, |21x9|, [quebra: 21:9], [quebra: 21x9].
// Cada marcador quebra apenas na proporção correspondente; senão vira espaço.
// As proporções são faixas: vertical <= 0.85; 4:3 > 0.85 e <= 1.45;
// 16:9 > 1.45 e < 2.1; ultrawide >= 2.1.
// Use "quebra:" em minúsculas. Marcadores curtos entre [] não distinguem caixa.

// REFERÊNCIAS (também utilizadas internamente pela Bíblia)
// //ref: texto da referência; também aceita //ref texto.
// //ref-pos: top, bottom ou below. Use estes valores em inglês.
// //ref-alinhar: ou //ref-align: esquerda/left/l/e, centro/center/c,
// direita/right/r/d. Exemplo: //ref-align: right
// //ref-size: ou //ref-tamanho: small/compact/pequeno/reduzido (70%) ou normal.
// Todos estes comandos aceitam espaço em vez de dois-pontos.
// Para uma referência separada, use ref e ref-pos na mesma estrofe.
// Com ref-pos e várias linhas visíveis, a primeira (top) ou última (bottom/below)
// linha visível é usada como referência. ref é a alternativa com uma única linha.
// Estes comandos não selecionam uma passagem nem uma tradução da Bíblia.

// FORMATOS DE IMPORTAÇÃO
// Texto sem extensão, TXT, TEXT, MD/MARKDOWN: UTF-8 (com/sem BOM)
// ou UTF-16 com BOM. MD usa apenas os marcadores descritos, não HTML completo.
// LRC: lê título [ti:...] e artista [ar:...], removendo horários [00:12.30].
// SRT/VTT: extrai o texto das legendas; cada bloco vira uma estrofe.
// PPTX: texto na ordem dos slides definida na apresentação; um slide = estrofe.
// DOCX/ODT: extrai os parágrafos; parágrafos vazios separam estrofes.
// ODP: extrai texto das páginas; uma página = estrofe.
// Não importa imagens, notas do apresentador, animações, áudio ou fontes embutidas.
// PPT/DOC antigos, PDF, RTF e texto em codificações legadas não são suportados.
// Converta para PPTX/DOCX ou texto UTF-8 antes de importar.
// Não existem comandos para executar scripts, abrir arquivos ou baixar mídias.
