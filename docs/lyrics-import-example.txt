// COMMENTS AND LABELS
// Lines starting with // are comments, except recognized commands.
// // in the middle of a line removes the rest on projection (avoid URLs in lyrics).
// #* followed by any name labels the stanza and is not projected.
// Label examples: #*verse 1, #*chorus, #*bridge, #*ending.
// There is no automatic repeat command: copy the stanza to repeat it.
#*chorus
**Highlighted/bold** and ==highlighted==
*Italic* __underlined__ ~~strikethrough~~
// ** and == markers trigger the same theme visual highlight.
// Do not nest Markdown markers: this is not full Markdown.
[font: Arial]Span font[/font]
[color: #FFD700]Span color[/color]
[size: 56]Span size[/size]
[shadow: #000000]Span shadow/box[/shadow]
// Tags can be nested; close them before the end of the line.
// Tag and command names are case-insensitive.
// Colors: #RGB, #RRGGBB, or #RRGGBBAA. Sizes > 0; decimals with period.

// ALL ALTERNATIVE SLIDE COMMAND NAMES
// Names for font: font, f, fonte, fuente. Example: //f: Arial
// Names for color: color, c, cor. Example: //c: #FFF
// Names for size: size, s, t, tamanho, tamaño. Example: //s: 44
// Shadow/box: shadow, box, b, sombra, fundo. Example: //b: #000
// Alignment: align, a, alinhar, alinear. Example: //a: center
// Horizontal values: center/c/centro; left/l/esquerda/izquierda/i;
// right/r/direita/derecha/d; justify/j/justificado (subject to renderer support).
// Line spacing: line, l, linha, linea. Example: //l: 1.4
// Letter spacing: letter, ls, letra. Example: //ls: 1.5
// Vertical: valign, va, valinhar. Example: //va: center
// Vertical values: top/t/topo/cima/arriba; center/c/centro/meio/medio;
// bottom/b/inferior/baixo/abajo/terço inferior/tercio inferior.
// Always prefer colons. For line/linha/l, colons are mandatory.
// For others, space is also accepted: //f Arial or // a center.
// SPAN TAGS (always with colon at start and / at close):
// font/f/fonte/fuente; color/c/cor; size/s/t/tamanho/tamaño; shadow/box/b/sombra/fundo.
// Examples: [f: Arial]text[/f], [c: #FFF]text[/c],
// [s: 50]text[/s], [b: #000]text[/b]. Alignment is not a span tag.
#*bridge
//f: Arial
//c: #FFFFFF
//s: 44
//b: #000000
//a: center
//va: center
//l: 1.4
//ls: 1.5
Example with all appearance shortcuts

// CONDITIONAL BREAKS (do not create another slide)
// | or [br]: breaks on 4:3 screens; becomes a space on other aspect ratios.
// [4:3], [4x3], |4:3|, |4x3|, [break: 4:3], [quebra: 4:3].
// [16:9], [16x9], |16:9|, |16x9|, [break: 16:9], [quebra: 16:9].
// [9:16], [9x16], |9:16|, |9x16|, [break: 9:16], [quebra: 9:16].
// [21:9], [21x9], |21:9|, |21x9|, [break: 21:9], [quebra: 21:9].
// Each marker breaks only on the corresponding aspect ratio; otherwise becomes a space.
// Aspect ratio ranges: vertical <= 0.85; 4:3 > 0.85 and <= 1.45;
// 16:9 > 1.45 and < 2.1; ultrawide >= 2.1.
// Use "break:" or "quebra:" in lowercase. Short bracket tags are case-insensitive.
One phrase | on two lines on a 4:3 screen
Another phrase [16:9] breaking on widescreen
A phrase [9:16] for vertical displays
A phrase [21:9] for ultrawide displays

// REFERENCES (also used internally by the Bible module)
// //ref: reference text; also accepts //ref text.
// //ref-pos: top, bottom, or below.
// //ref-align: or //ref-alinhar: left/l, center/c, right/r. Example: //ref-align: right
// //ref-size: or //ref-tamanho: small/compact/reduzido (70%) or normal.
// All these commands accept a space instead of a colon.
// For a standalone reference, use ref and ref-pos in the same stanza.
// With ref-pos and multiple visible lines, the first (top) or last (bottom/below)
// visible line is used as reference. ref is the single-line alternative.
// These commands do not select a Bible passage or translation.
#*ending
//ref: Demonstration Reference
//ref-pos: below
//ref-align: right
//ref-size: normal
//valign: center
