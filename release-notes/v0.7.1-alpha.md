## Omni Presenter 0.7.1 alpha

This maintenance alpha release introduces language-aware default Bible version selection, improves Windows build and packaging dependencies, and refines release automation workflows.

## Highlights

- **Language-Aware Bible Defaults**: Automatically selects the appropriate bundled Scripture translation based on the active interface language (Portuguese, Spanish, or English).
- **Windows Build Compatibility**: Includes vendored OpenSSL support for Windows targets to ensure reliable builds and binary packaging without external OpenSSL installation requirements.

## Improvements

- **Release Workflow Optimization**: Release tooling (`tools/release.py`) now supports rebuilding and updating existing release tags that point to the current commit.
- **Bible Selector Synchronization**: Improved Bible version bar to reliably update and persist preferred translations across sessions.

## Known issues

- None reported.

## Installation

Download the archive for your operating system and architecture, verify it against `SHA256SUMS.txt`, and extract it. See the included `operations.md` for runtime requirements and workspace storage.

This is an alpha release; test your presentation setup before using it at an event.
