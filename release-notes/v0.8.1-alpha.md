# Omni Presenter 0.8.1-alpha

## Highlights

- **Default Monitor Aspect Ratio Matching**: The setup wizard and presentation settings now default to matching the selected monitor's native aspect ratio automatically (`Proporção do monitor selecionado`), with quick presets for 16:9, 16:10, 4:3, and 21:9.
- **Deletion Confirmation Dialogs for Themes, Songs, Media & Playlist**:
  - Added a dedicated, localized confirmation modal dialog when deleting custom themes, library items (songs, media items, custom texts, saved verses), library folders, or clearing the entire playlist.
  - Dialogs present contextual warnings with the exact item name or batch count (e.g. `Tem certeza de que deseja excluir o tema "..."? Esta ação não pode ser desfeita.`), a neutral `Cancelar` button, and an elevated danger `Excluir` button.
  - Keyboard navigation allows confirming deletion via `Enter` or dismissing via `Esc`, and modal suppression prevents global hotkeys from triggering inadvertently while the dialog is active.
- **Streamlined Media Player, Performance & Hardware Acceleration**:
  - Added a **Hardware Acceleration** preference in Settings (`Aceleração de hardware na decodificação de vídeo`), enabling FFmpeg hardware decoding (`-hwaccel auto` across VA-API, NVDEC, D3D11, and VideoToolbox) for smoother playback and drastically lower CPU consumption.
  - Implemented native frame rate probing (`23.976`, `24`, `29.97`, `30`, `60` fps) with sub-millisecond consumer frame pacing, eliminating frame drops, pulldown judder, and stutter caused by forced 30 fps resampling on 24 fps cinematic/music videos.
  - Removed FFmpeg pipe `-readrate` throttling that caused buffer starvation and desynchronization during 720p/1080p playback.
  - Configured multi-threaded row and tile-column parameters (`-row-mt 1`, `-tile-columns 2`) when converting to WebM (VP9), unlocking multi-core decoding performance.
  - Unlocked multi-threaded decoding and filtering (`-threads 0`), utilizing available CPU cores rather than restricting playback to 2 threads.
  - Eliminated ~110 MB/s of continuous frame buffer heap allocations by reusing frame memory across decoded frames.
  - Optimized the filter graph to bypass expensive CPU pixel equalizers (`eq`) when contrast and saturation are at their defaults.
  - The player now automatically ends the active projection when video playback finishes, preventing the presentation window from being left open on a black screen.
  - Smooth fade-out and close animation for the player container upon video completion.
  - Removed the redundant video preview frame from inside the Player panel, focusing playback visualization exclusively in the dedicated Visualização (Stage / Preview) panel.
- **Video Display Fit Modes**:
  - Redesigned the display fit selector into a unified, tactile segmented capsule track with contextual Phosphor icons (`[ ⇲ Conter | ⇱ Cobrir | ⇄ Estender ]`), subtle unselected dividers, and elevated active pill highlight.
  - Fixed low-contrast dark gray text in Darker Pro theme on the active segment, delivering clear high-contrast typography and smooth hover feedback.
  - One-click selection between **Conter** (Contain - preserve full video aspect ratio without cropping), **Cobrir** (Cover - fill projection canvas, cropping edges when aspect ratios differ), and **Estender** (Stretch - stretch video to fill canvas).
  - Mode selections immediately propagate to both Preview and live Projection outputs.
- **Expanded Media Conversion, Resolutions & Aspect Ratios**:
  - Added video codec selection in the conversion modal: **Auto**, **H.264** (`libx264`), **H.265 / HEVC** (`libx265`), **VP9** (`libvpx-vp9`), and **AV1** (`libsvtav1`).
  - Expanded video conversion formats with **MP4** (H.264/AAC), **WebM** (VP9/Opus), **MKV** (Lossless FFV1/FLAC), and **MOV** (QuickTime).
  - Added video aspect ratio conversion options: **Manter original (Recomendado)**, **16:9**, **16:10**, **4:3**, **9:16 (Vertical)**, and **21:9 (Ultrawide)**.
  - Added video resolution downscaling presets with current source resolution detection and display: **Original (Recomendado)**, **4K (2160p)**, **1080p (Full HD)**, **720p (HD)**, and **480p (SD)**.
  - Expanded audio conversion formats with **MP3** (320 kbps), **FLAC** (Lossless), **WAV** (PCM), **AAC** (M4A), and **OGG** (Vorbis).
  - Added **JPEG** support alongside **PNG** and **WebP** for images.
- **Synchronized Video Audio Playback & Frame Pacing**:
  - Implemented real-time audio playback for video files by piping high-fidelity 32-bit float stereo PCM directly from FFmpeg into Rodio's native audio engine with seamless volume, muting, and seek synchronization.
  - Video audio now plays strictly when projected live (`Ao Vivo`), remaining completely silent in Preview/Visualização.
  - Pressing `Esc` (or closing/toggling the presentation) immediately pauses audio playback and stops projection, preventing background audio leakage.
  - Resolved timeline scrubbing desynchronization: seeking on the timeline now passes the exact target offset (`-ss`) to both the video decoder and audio stream, keeping both in sync instead of resetting video frames to the beginning.
  - Replaced per-pixel float color transformation with raw zero-copy `ColorImage::from_rgba_premultiplied` byte copy and optimized dependency compilation profiles, eliminating UI thread bottlenecks during video decoding.
  - Corrected video playback loop timing using monotonic frame pacing, eliminating cumulative loop overhead drift and frame judder.
  - Resolved Media Info modal parser bug where video codec displayed the audio stream codec (e.g. OPUS).
- **Media Information Inspector & Refined Progress**:
  - Added an **Informações da mídia** context menu action for library media, showing complete dimensions, aspect ratio, duration, codecs, file size, and container details.
  - Fixed the floating conversion toast width to remain compact and sleek, avoiding excessive horizontal stretching.
  - Hovering over the floating conversion toast or actively converting library items now presents rich video metadata (filename, resolution, duration, codecs, and percent).
  - Library item rows actively converting in the background display an inline progress bar and percentage (`45%`), keeping operators informed of progress at a glance.
- **Redesigned Operator Profile Welcome Dialog**:
  - Vertically centered operator avatars and names within the profile selection cards, eliminating top-heavy misalignment and unbalanced bottom whitespace across active and inactive profiles.
  - Fixed severe contrast loss in dark themes where selected operator names rendered in low-contrast accent gray on dark card backgrounds.
  - Removed the redundant `Ativo` status pill in favor of a clean checkmark badge directly on the avatar and accent highlights, ensuring consistent vertical centering across all cards.
  - Removed unlocalized quick-select string on hover, providing clean interactive card states with smooth borders and hover highlights.
  - Restructured card dimensions and modal clearance so the primary action button (`Entrar como...`) is never clipped or pushed offscreen.
  - Added an accessible close (`X`) button in the top-right corner.
- **Rounded Corner Clipping in Preview & Live Stage Displays**:
  - Implemented `paint_textured_rounded_rect` so that video frame quads, image backgrounds, shaders, and design canvases rendered within the Visualização (Preview) and Retorno Ao Vivo (Stage) display panels cleanly adhere to the container's rounded corner radius (`theme.radius_lg`).
  - Eliminated sharp square corner artifacts and removed solid corner mask triangles that previously produced discolored square corners outside the rounded border strokes.
- **Web Stage Directives Concealment & Integrated Next Strophe Flow**:
  - Automatically hides raw slide formatting commands (`//t:`, `//c:`, `//f:`, `//sombra:`, etc.) and inline tags (`[T: 60]...[/T]`, `[C: #HEX]...[/C]`, `[F: ...]...[/F]`, `[B: ...]...[/B]`) on web screens ([`strip_directive_commands`](file:///home/lewis/Projetos/omni-presenter/src/core/slides.rs#L784-L789), [`appendFormattedRuns`](file:///home/lewis/Projetos/omni-presenter/assets/web/viewer/viewer.js#L115-L175)), ensuring colors and styles are applied without raw syntax cluttering stage displays.
  - On web screens with next slide preview enabled (`show_next_preview`), the upcoming strophe now renders directly with the active lyrics in an integrated, dimmed secondary color (`.next-strophe`), eliminating the detached floating footer badge in favor of a cohesive confidence monitor reading flow.
- **Smooth Optical Gaussian Blur Transition**:
  - Replaced low-tap displaced text rendering and sparse Vogel spiral sampling with a continuous concentric multi-ring Gaussian convolution kernel with golden-ratio angular phase shifts between rings ([`render_blurred`](file:///home/lewis/Projetos/omni-presenter/src/render/text.rs#L450-L510)).
  - Completely eliminated the fine pixelated lattice, moiré fringes, and screendoor grid artifacts caused by Fibonacci parastichies and integer-snapped font glyph offsets.
  - Dynamically attenuated both the center text sample and shadow core proportionally to blur radius, eliminating sharp unblurred ghost cores and harsh dark shadows inside the diffusion cloud.
  - Introduced subtle optical lens defocus expansion (~2.5%) during transition ([`draw_layer`](file:///home/lewis/Projetos/omni-presenter/src/services/effects.rs#L189-L195)), delivering silky, cinematic rack-focus transitions without pixelation or stippling.
- **Keyboard Verse Projection via Enter**:
  - Pressing `Enter` with a Bible verse or range selected now immediately projects the passage live ([`render_bible_text`](file:///home/lewis/Projetos/omni-presenter/src/ui/pages/bible/text.rs#L169-L185)), matching operator muscle memory without requiring a double-click or mouse click on the present button.
- **Playlist Multi-Selection & Combined Sequential Projection**:
  - Implemented multi-selection in the playlist container with `Shift` (contiguous range selection) and `Ctrl`/`Cmd` (toggling individual items) using [`Selection`](file:///home/lewis/Projetos/omni-presenter/src/core/interaction.rs#L4-L53).
  - Multi-selected playlist items can now be projected together as one seamless continuous slide presentation: advancing slides (`ArrowRight`, `Space`, or dock controls) flows directly from one item into the next without stopping or manual switching.
  - Multi-selection with mixed media items (videos, images, audio) now displays the actual media instead of raw filename text slides: dock slide cards render the media's live frame/thumbnail without text overlay, video playback and audio engage automatically when advancing to media slides, and playback cleanly pauses when stepping back to songs or Bible passages ([`SlideDeck::load_custom_slides_with_media`](file:///home/lewis/Projetos/omni-presenter/src/core/slides.rs#L425-L445), [`sync_live_media_playback`](file:///home/lewis/Projetos/omni-presenter/src/services/media.rs#L130-L165)).
  - Added multi-item batch drag-and-drop reordering, batch status toggle, batch removal (`Delete`/`Backspace`), `Ctrl+A` select all, and keyboard projection via `Enter`.
- **Persistent Presentation Dock Size & Preview Mode Across Restarts**:
  - The presentation dock panel height (`dock_height`), slide-card preview style (`dock_preview_bg` between `Texto` and `Fundo`), and lyrics card/list view mode (`lyrics_cards_layout`) are now persisted into the active operator profile.
  - Resizing the dock immediately records and persists the new height so slide card thumbnails retain the chosen scale and mode when reopening the program or closing the window.
  - Added immediate close event handling to flush and commit profile changes on window close.
- **Pure Neutral Darker Pro Palette**:
  - Completely eliminated bluish/slate undertones from the Darker Pro dark theme in favor of true monochrome carbon/charcoal neutrals ($R = G = B$).
  - Active toggle switches now feature solid `#505050` tracks with crisp white knobs (`#FFFFFF`), delivering clear 8:1 contrast.
- **Intelligent Text Truncation in Playlist and Library**:
  - Long file and playlist item titles now truncate gracefully with ellipsis (`…`) within available bounds, ensuring text never overlaps the played status toggle icon or bleeds off-panel.
  - Hovering over playlist items reveals their full title and subtitle via native tooltips.
  - Reserved dedicated subtitle clearance (`subtitle_reserve`) and fixed-height bounded label allocation in the Visualização (Preview) and Ao Vivo (Stage) containers, preventing song/artist titles (e.g. `10,000 Reasons · Jesus Culture`) from being clipped by panel borders or resize dividers.
  - Enforced strict container height bounds (`ui.set_max_height`) in workspace docking frames, preventing content overflow from pushing container cards off-bounds or clipping bottom borders and rounded corners.
- **Workspace Layout Restoration & Localized Actions**:
  - Fixed interface layout reset buttons in Settings (`Interface` tab): clicking now immediately resets the active workspace (`layout`, `bible_layout`, and `chat_layout`), persists the restored layout, and displays instant feedback toasts.
  - Added missing localization key `settings-restore` across English (`Restore`), Portuguese (`Restaurar`), and Spanish (`Restaurar`), resolving the bug where raw translation keys appeared inside button labels.
- **Opaque Global Search Palette**:
  - Removed full-workspace disablement during global search that caused window opacity degradation and desktop wallpaper bleed-through on composited window managers.
  - Made the global search modal backdrop transparent and elevated the floating search palette with a clean drop shadow, keeping the workspace solid and fully visible.
- **Refined Iconography & Setup Flow**:
  - Replaced decorative sparkle icons across setup wizard steps, about modal, design templates, and transitions with contextual symbols (`HAND_WAVING`, `PROJECTOR_SCREEN`, and `PULSE`).
  - Streamlined the setup wizard breaks step for a cleaner onboarding experience.
