## Omni Presenter 0.7.0 alpha

This alpha provides a desktop workspace for preparing and presenting lyrics, Scripture, media and visual designs, with browser-based control and team chat.

## Installation

Download the archive for your operating system and architecture, verify it against `SHA256SUMS.txt`, and extract it. See the included `operations.md` for runtime requirements and workspace storage.

This is an alpha release; test your presentation setup before using it at an event.
