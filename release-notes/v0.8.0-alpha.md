# Omni Presenter 0.8.0-alpha

## Highlights

- **Initial Setup Wizard**: Guided onboarding on first launch to configure projection displays, interface language, presentation aspect ratio, automatic line wrapping, and font auto-fit.
- **Dynamic Shader Themes First**: Featured animated shader themes (Aurora, Nebula, Waves, Silk, etc.) now appear at the top of the theme selector by default, with new user-created themes seamlessly placed first.
- **Full Theme Internationalization**: Default static themes and dynamic shader presets are now fully localized across English, Portuguese, and Spanish throughout the theme grid, presentation dock, slide controls, and web control panel.
- **Compact & Universal Slide Commands**: Introduced intuitive shorthand directives (`//t:`, `//f:`, `//c:`, `//a:`, `//l:`, `//ls:`, `//b:`) and selection tags (`[t:]`, `[f:]`, `[c:]`, `[b:]`) with case-insensitive parsing and seamless directive replacement.
- **Instant Lyrics Synchronization**: Saving edited lyrics immediately refreshes active strophe cards, presentation slide deck, and live output with complete inline color and style rendering.
- **High-Quality Media Conversion**: Convert imported images, video, and audio into high-quality standardized formats, or keep originals, with options to convert existing library assets on demand.
- **Projection-Accurate Lyrics Previews**: Lyrics stanza cards now render formatting, font styles, and automatic line wraps identically to the live projection window.
- **Remote Web Control Improvements**: Comprehensive translation and key-normalization fixes across web control panels, theme swatches, and stage indicators.
- **Startup Profile Selection**: Dedicated operator profile picker on startup when multiple profiles exist, featuring profile avatars, quick enter shortcuts, and settings control.
- **Enhanced Event Recurrence & Defaults**: Flexible recurrence schedules including multiple chosen dates, sequential multi-day events, monthly week-of-month selectors, all-day event toggles, and per-event default themes and wallpapers.
- **Live Interface Theme Preview**: Selecting interface themes or appearance modes in Settings now previews them instantly across the entire application interface in real time, automatically reverting if closed without saving.
