# Omni Presenter 0.8.3-alpha

> Draft for the next release. Compared with `v0.8.2-alpha`, including the current development working tree. This release has not been published.

## Highlights

- **More reliable Bible projection:** corrected missing references, reference alignment and verse centering, with a settings preview that now uses the real presentation renderer.
- **Your presentation choices are remembered:** the last clicked theme is restored per event, and Bible list/card layout is saved per operator profile.
- **A more consistent workspace:** improved Bible settings scrolling, better-sized Bible cards and a Designs library empty state matching the other library tabs.
- **Safer persistence and builds:** startup no longer silently falls back to temporary storage, theme ordering is saved atomically, and failed web compilation now stops the build.
- **Portable backups and file-based lyrics:** export/restore the workspace from Settings, or import text and presentation documents as new songs with editable previews.

## Workspace import/export and lyrics files

- Added **Settings → Import / Export** with portable ZIP backups of settings, profiles, event/session playlists, shortcuts, songs and linked versions, themes, designs, media, texts, saved verses, folders, installed Bible translations, interface themes and plugins.
- Compact action cards separate export, restore and lyrics import, with optional help collapsed by default. The navigation entry appears immediately above **About**.
- Referenced local images/media are included and relocated on restore. Online media remains linked; missing local files are reported.
- Restore includes a package preview, explicit replacement confirmation, a mandatory recovery ZIP and transactional database replacement. The app closes afterward without overwriting imported settings; reopen from the same workspace directory.
- Added separate **additive lyrics import** from extensionless/text/Markdown, LRC, SRT, VTT, PPTX, DOCX, ODT and ODP files, with song selection and editable previews. Existing songs are not replaced and prepared/live output is preserved.
- Presentation imports extract text only, not images, animations or layout. Added a downloadable/importable example TXT documenting metadata, comments, stanza labels, formatting, references and conditional breaks.
- File dialogs, archive operations and document parsing run in background workers. Backups are not encrypted; only import trusted packages. Chat history/uploads, certificates, installed fonts, caches and external tools are excluded.
- See `docs/import-export.md` for scope, format limitations, recovery instructions and safety limits.

## Web control

- Preview and live monitors use the actual browser outputs, without duplicate text or status overlays. Concealing lyrics keeps the live monitor and theme background visible.
- Standard browser text layers share native projection layout, fonts, markup and Bible reference positioning, rendered asynchronously as cached transparent PNGs at 720p design resolution. Browser backgrounds, shaders and designs still use their browser renderers; this does not guarantee pixel-identical output for every presentation type.
- Bible translation selection now includes searchable, language-filtered choices and pinned, reorderable shortcuts. Translation, passage, grouped-verse and list/card choices synchronize with the desktop application without replacing live content.
- The song editor adds folder/tag metadata, formatting controls, stanza counts and reorder/duplicate/delete actions, unsaved-change confirmation and Ctrl/Cmd+Enter saving. Older clients preserve metadata they do not send.
- Playlists support multiple selection, stable-ID group moves, library drops, duplication, batch played-state updates, keyboard operations and actual persistence. Clearing a playlist requires confirmation.

## Bible presentation

### Reference placement and typography

- Fixed references disappearing when drawn outside the theme's verse text box. Top, bottom and below-text references now use the correct alignment anchors and clipping area.
- Fixed centered Bible alignment silently inheriting a theme's lower or right-aligned placement. Explicit Bible alignment is retained when separating the verse from its reference.
- Top and bottom references no longer shift a centered verse when switching between those positions, including themes with an offset text box.
- The Bible Settings preview now shares the content formatter and native renderer used for presentation, rather than reimplementing positioning, quotation marks and typography independently.
- Sample previews follow the selected presentation aspect ratio and continue to support John 3:16, Psalm 23:1–2 and Romans 8:28.
- Summarized verse numbers are placed **outside quotation marks**, for example `[16] “Verse text…”`. This works with bracket, superscript and dotted numbering, including verses split into multiple slides.
- Removed the **Reference Highlight** selector (Subtle / Accent / Pill or Badge) from Bible Settings. Previously saved highlight values remain readable for compatibility.

### Updated defaults

New Bible settings and **Restore defaults** now use:

| Setting | Default |
| --- | --- |
| Reference position | Below the verse text |
| Reference alignment | Right |
| Verse alignment | Center |
| Vertical placement | Center |
| Chapter/verse separator | Dot, such as `John 3.16` |
| Verse numbering | Brackets, such as `[16]` |
| Summarize references across a multi-verse selection | On; intermediate slides show the verse number, with the full range on the last slide |
| Numbering in grouped verses | On |
| Reference size | Normal |
| Quotation marks around verse text | On |
| Translation code, book abbreviations, uppercase reference and italic reference | Off |

Existing explicitly saved settings are preserved. Use **Restore defaults** in Bible Settings to apply the new defaults to an existing workspace.

### Settings and navigation

- Bible Settings now fits within the available window height, with a visible scrollbar for the preview and options. The title, tabs and action buttons remain outside the scrolling body.
- The settings footer adapts to narrower windows so **Done**, **Restore defaults** and translation management remain accessible.
- Bible card panels account for their borders, padding and actual available column width. Grids are calculated inside the scrollable viewport so the scrollbar does not cut off the last column.
- Books, chapters and verses have visible, independent scrollbars, making long chapter lists easier to navigate without overflowing their panels.
- Switching between Bible list and card layouts is now persisted per operator profile and restored after reopening or changing profiles.
- Fixed **Remove from shortcuts** for Bible translations: removing the active translation no longer immediately adds it back on the next redraw or profile reload. An intentionally empty shortcut bar is preserved; new profiles still receive their initial default.

## Themes and workspace consistency

- The last theme clicked in the preview is saved by its stable ID and restored per event, even if the theme list has been reordered.
- Remembering a preview selection does not replace the live theme during a session or overwrite the event's configured default theme.
- Explicitly changing an event's default theme takes precedence over an older remembered selection. If a remembered theme has been deleted, restoration falls back to the event default and then an available theme.
- The **Designs** library now uses the same centered empty-state component as Lyrics, Media, Text and Verses: a muted icon, title, explanation and consistently styled action button.
- Empty design searches offer **Clear search**, while an empty unfiltered Designs library offers **Create design**.

## Reliability and data safety

- If the workspace database cannot be opened, startup stops with an explicit, localized error showing the resolved database path. The application no longer appears to save successfully into an automatically substituted in-memory database.
- Invalid saved preferences also prevent normal startup instead of being silently replaced by defaults through autosave or shutdown.
- Theme reordering now runs in a single SQLite transaction. Failed writes or missing theme IDs roll back the batch instead of leaving a partially saved order, and callers report failures to the operator.
- Added English, Brazilian Portuguese and Spanish messages for startup failures, theme-order errors and Bible sample-preview status.

## Build, quality and development

- Kept updated dependencies, including `zip` 9.5.1, `rusqlite` 0.42 and `resvg` 0.50. Adapted archive validation to the fallible ZIP filename API, with regression coverage for Unicode asset names and mismatched manifest references rather than downgrading the libraries.
- **Web compilation is mandatory:** missing Bun, missing local TypeScript dependencies or a failed frontend build now stop the Rust build instead of silently packaging potentially stale web assets.
- The web build uses the installed TypeScript compiler rather than downloading a compiler implicitly through `bun x`; changes to the frontend lockfile also trigger rebuilding.
- Added pull-request and main/master quality checks covering Rust tests, TypeScript, translation catalogs, architecture constraints and a reviewed Clippy warning budget.
- CI and release builds use Rust **1.98.0** and Bun **1.4.4**, with frozen frontend dependencies. Bun is a **source-build requirement**, not a runtime requirement for the packaged desktop application.
- Added regression tests for closing and reopening with a selected theme, profile persistence, reference layout, quotation marks, removed translation shortcuts, narrow card panels, shared empty states, failed database writes and web-build failures.
- Added a lightweight architecture guard against new direct UI/runtime dependencies in domain modules, with explicit exceptions for legacy adapters.
- Updated the build, operation, persistence and release documentation in the repository.

## Upgrade notes and known limitations

- Back up the workspace database and any externally referenced assets before upgrading. Existing explicitly saved Bible preferences are retained, and stored playlist content is not rewritten to adopt the new presentation defaults.
- Workspace location still depends on the application's working directory. Existing databases are not moved automatically; start from the intended workspace directory.
- When startup reports an inaccessible database or invalid preferences, check the reported path, permissions and available disk space, or restore a backup. This change does not automatically repair damaged data.
- This remains an alpha release. Tests requiring a graphical compositor, Chromium/Playwright or multicast networking are not part of the default local test run; release packages still need platform-specific validation.
- The Clippy budget tracks existing warning counts rather than claiming a warning-free codebase. Repository-wide formatting cleanup remains separate, and its CI report is informational.
- Local regression coverage includes workspace/archive roundtrips, imported media relocation, failed-recovery and failed-transaction rollback, explicit restore confirmation, supported lyrics document formats and protection against stale settings on exit. Environment-dependent compositor, browser and network tests remain separate; this is not a claim that release packages have already been tested on every platform.

## Installation

Once this release is published, download the package for your operating system and architecture, verify it against `SHA256SUMS.txt`, and follow the included `operations.md`. Video playback and supported web-video extraction continue to require the documented external tools, such as `ffmpeg`, `ffprobe` and `yt-dlp`.

For source builds, initialize the Bible submodule, install Bun 1.4.4 and run `bun install --cwd web --frozen-lockfile` before building with Cargo. See `docs/development.md` and `docs/releases.md` for the complete instructions.
