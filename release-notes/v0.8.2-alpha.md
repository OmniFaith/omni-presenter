# Omni Presenter 0.8.2-alpha

## Highlights

- **Visual Presentation Dock Theme Selector**:
  - Replaced the plain text dropdown menu in the presentation dock with a rich 2-column visual grid of live theme preview cards.
  - Each card accurately renders the theme's background (shader, gradient, image, or solid color), typographic styling sample, translucent name strip, gold star indicator for favorites, and active checkmark badges with accent border highlights.
  - Includes a real-time theme search input to filter themes instantly by name or localized title.
- **Drag-and-Drop Bible Translation Reordering**: Quick translation pills on the Bible navigation bar can now be reordered via drag-and-drop. Dragging any version pill left or right displays a real-time insertion indicator, and the custom sequence is automatically persisted to the active service profile (`state.settings.services`) and shortcuts.
- **Lyrics Editor Full-Area Focus & Clipboard Context Menu**:
  - The lyrics text editor now expands to cover the entire container area, allowing operators to click anywhere inside the box to focus and position the blinking caret immediately.
  - Added a right-click context menu offering **Paste**, **Copy**, **Cut**, and **Select All** operations, making it easy to paste and manage lyrics copied from external sources.
- **Card Focus, Tab Navigation & Contextual Enter Handling**:
  - Implemented card-level focus tracking across all workspace containers (`state.focused_container`). Clicking on any card (or using `Tab` / `Shift+Tab`) focuses that card with an elegant visual accent stroke.
  - The `Enter` key now operates contextually according to the focused card: presenting selected items in the Library (Selection), projecting the active preview stanza in Lyrics, applying the chosen theme in Themes, and playing items in the Playlist only when the Playlist card is focused.
  - Added `Ctrl+Tab` and `Ctrl+Shift+Tab` global keyboard navigation to cycle seamlessly between application interfaces (Presentation Workspace, Bible, Chat, and Design).
  - Fixed the stanza jump input in the presentation dock (`src/ui/components/presentation_dock/transport.rs`) to consume the `Enter` key upon submission, ensuring slide jumps execute directly and are never intercepted by the playlist.
- **Alphabetical Operator Profile Sorting**: Operator profiles in the welcome dialog ("Who is operating today?") and the web chat profile picker are now automatically sorted in alphabetical order for faster selection.

## Improvements

- **Top Shortcut Bar Vertical Centering**: Resolved baseline misalignment and top-hugging in the top shortcut bar (`src/ui/components/top_bar.rs`), ensuring the "Atalhos" header label, shortcut item pills, and right-hand options cluster (operator, service, screens, status) all share a unified, balanced vertical center line.
- **Redesigned Shortcut Pinning Drop Target**: Replaced the awkward oversized overlay badge with an elegant in-line drop target pill (`[ 📌 Fixar nos atalhos ]`) and smooth rounded boundary glow across the shortcuts zone during drag-and-drop operations, keeping the section title legible and providing clear, localized drop feedback.
- **Dynamic Operator Profile Avatars in Private Chat**: Operator entries under "Private Messages" in the chat navigation sidebar now display circular profile avatars (rendering the operator's uploaded photo or high-contrast stylized capitalized initials when no custom photo is set). The online/offline status dot is now positioned neatly on the bottom-right corner of the avatar circle with an outline ring for clarity.
- **Emphasized "Projetar" Action Button**: Restyled the projection call-to-action on shared chat messages (`src/ui/pages/chat/messages.rs`) into a vibrant primary button with solid accent fill (`tokens.accent`), high-contrast bold white typography (`tokens.text_on_accent`), interactive hover states, and a pointing hand cursor, replacing the previous muted gray appearance that made it look disabled.
- **Cleaned Up Message Action Bar**: Removed the non-functional "Copy content link" button from the shared message header actions bar, eliminating confusing dead actions and keeping quick actions focused on projecting, pinning, and adding to playlists.
- **Interactive Service Hover Highlights**: Added tactile hover backgrounds and subtle border accents across past, same-day, and upcoming services in the playlist footer service-picker popup.
- **Input Field Inner Margins & Padding**: Corrected frame inner margins across single-line text inputs, search fields, and color pickers in Settings and dialogs, ensuring text, search icons, and placeholders have clean, balanced breathing room rather than touching the rounded container borders.
- **Web Chat Reaction Handlers**: Restored click interactions and event listeners for reaction emojis on chat messages in the web remote interface.
- **Compiled Web Assets Packaging**: Bundled precompiled web application assets directly into the repository and release workflow, ensuring reliable cross-platform builds without host runtime dependencies.
- **Common Action Translations**: Added multilingual Fluent translation strings for standard clipboard actions across Portuguese (`pt-BR`), English (`en`), and Spanish (`es`).
