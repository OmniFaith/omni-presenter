# Project instructions

- Use Graphify when exploring or answering questions about this codebase. When `graphify-out/graph.json` exists, query the existing graph before inspecting relevant source files. If the graph or tool is unavailable, state the limitation and continue with the available project tools.
- Keep dependencies up to date. When an update changes an API, adapt the application and tests to the updated library instead of downgrading dependencies to make the build pass. Preserve updated lockfiles and validate compilation, tests and the Clippy budget after compatibility changes.
- Always use Graphify for codebase exploration and Headroom to manage context during project work.
